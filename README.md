# Абитура

Тренажёр для подготовки к внутренним вступительным испытаниям вузов по математике, информатике и русскому языку. Устроен как Duolingo: короткая теория, практика, повторение ошибок по расписанию. Работает в браузере без интернета и без установки.

Программы внутренних экзаменов у вузов строятся на кодификаторе ЕГЭ, поэтому темы подходят для любого вуза. Банк заданий собран из реальных материалов: демоварианты АлтГТУ и открытые билеты ТУСУР 2025.

## Запуск

Открыть `index.html` в браузере. Сборка, сервер и зависимости не нужны. Прогресс хранится в `localStorage`.

## Возможности

- **Три курса**: математика (11 тем), информатика (8 тем), русский язык (9 тем). Темы разбиты по сложности: разминка, практика, сложные, вступительный уровень.
- **Уроки**: сначала теория, затем задания четырёх форматов — выбор ответа, ввод ответа, несколько верных вариантов, сопоставление пар.
- **Интервальные повторения** по системе Лейтнера: ошибка возвращается через 1, 2, 4, 7 и 14 дней. После последнего интервала задание считается выученным.
- **План на день** на главном экране: новый урок, повторение и блиц. Кнопка «Продолжить» сама выбирает, что полезнее сейчас.
- **Блиц**: 60 секунд, задания вперемешку из всех предметов, серии и рекорды.
- **Генераторы задач** (более 40): задания по математике, информатике и русскому собираются случайно, поэтому тренироваться можно бесконечно. Сложность подстраивается под ответы.
- **Пробный экзамен** по демовариантам: таймер, шкала 100 баллов, сравнение с проходным баллом и полный разбор после завершения.
- **Справочник терминов**: около 45 понятий с примерами. Термины в теории кликабельны, определение можно дополнить выжимкой из Википедии.
- **Геймификация**: опыт, ежедневная серия с заморозками, уровни тем, 16 достижений.
- **Резервная копия**: экспорт и импорт прогресса файлом, чтобы перенести его в другой браузер.
- **Экспериментальное** (включается в настройках): курс азбуки Морзе с озвучкой и генератор новых заданий через Claude API.

## Генератор заданий через LLM

Модуль `ai.js` по запросу пользователя просит модель составить новое задание по выбранной теме. Ответ приходит строго по JSON-схеме (structured outputs): текст задания, тип, варианты, правильный ответ и решение — поэтому его не нужно разбирать вручную и он сразу попадает в обычный экран задания.

Ключ API вводит сам пользователь в настройках; он хранится только в его браузере и никуда, кроме API, не отправляется. По умолчанию функция выключена.

## Стек

- Чистый JavaScript, HTML, CSS — без фреймворков и сборщика.
- SVG-иконки собственным набором, светлая и тёмная темы, несколько палитр.
- Web Audio API для звуков и озвучки азбуки Морзе.
- Тесты: Node.js (движок и данные), Python + Playwright (интерфейс в настоящем браузере).

## Устройство

Курсы подключаются через общий реестр `COURSES`: каждый файл данных регистрирует свой курс (темы, теорию, пул заданий, генераторы), экраны строятся по нему одинаково.

| Файл | Что это |
|---|---|
| `index.html` | точка входа, подключает скрипты по порядку |
| `style.css` | оформление, темы, палитры |
| `icons.js` | набор SVG-иконок |
| `core.js` | ядро: реестр курсов, прогресс, интервальные повторения, достижения, настройки, справочник |
| `screens.js` | экраны: главная, курс, теория, задание, умная тренировка, блиц |
| `exam.js` | пробный экзамен: таймер, подсчёт баллов, разбор |
| `stats.js` | статистика, настройки, запуск приложения |
| `ai.js` | генератор заданий через LLM |
| `data_math.js`, `data_inf.js`, `data_rus.js` | курсы: теория, задания, генераторы |
| `data_morse.js` | экспериментальный курс азбуки Морзе |
| `glossary.js` | справочник терминов |
| `tests/` | автотесты |

Чтобы добавить задание, достаточно дописать объект в `pool` нужной темы в файле данных.

## Тесты

```bash
node tests/engine.js
```

Загружает приложение в Node с заглушкой DOM и проверяет: структуру данных всех курсов, каждый генератор (300 прогонов), проверку ответов всех форматов, интервалы повторений, блиц, план дня. Сейчас 68 проверок.

```bash
pip install playwright && playwright install chromium
python tests/ui.py
```

Смоук-тест интерфейса в headless Chromium: открывает курсы, теорию, справочник, урок, проверяет, что в консоли нет ошибок.

## Методика

В основе три техники с самой сильной доказательной базой: активное воспроизведение (retrieval practice), интервальные повторения (spacing) и чередование тем (interleaving).
